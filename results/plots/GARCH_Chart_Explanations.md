# GARCH 波動率分析圖表說明

本文檔詳細解釋 GARCH 模型生成的各種圖表，幫助您理解波動率分析結果。

## 📊 圖表總覽

GARCH 分析會生成 6 個重要圖表，每個圖表都揭示了加密貨幣波動率的不同特徵：

### 1. 收益率時間序列 (Returns Time Series)
**位置**: 左上角  
**顏色**: 藍色線條

**什麼是收益率？**
- 收益率 = (今天價格 - 昨天價格) / 昨天價格 × 100%
- 顯示每個時間點的價格變化百分比

**如何解讀？**
- 📈 **正值**: 價格上漲
- 📉 **負值**: 價格下跌  
- 🎯 **波動大小**: 線條上下擺動幅度越大，表示價格變化越劇烈
- ⚡ **波動聚集**: 如果看到某些時期波動特別大，這就是"波動率聚集"現象

**實際意義**:
```
收益率 +5%  = 價格上漲 5%
收益率 -3%  = 價格下跌 3%
收益率接近0 = 價格幾乎沒變
```

---

### 2. 收益率分佈 (Returns Distribution)
**位置**: 右上角  
**顏色**: 天藍色柱狀圖 + 紅色正態分佈曲線

**這個圖在說什麼？**
- 顯示收益率的頻率分佈
- 紅線是"理想"的正態分佈
- 藍色柱子是"實際"的分佈

**如何解讀？**
- 📊 **中間高**: 大部分時候收益率接近 0（價格變化不大）
- 📊 **兩邊低**: 極大漲跌比較少見
- ⚠️ **偏離紅線**: 如果藍色柱子和紅線差很多，說明：
  - 市場有"肥尾"現象（極端事件比預期多）
  - 可能有偏度（更容易漲還是跌）

**投資意義**:
```
正態分佈 (紅線) = 教科書理論
實際分佈 (藍柱) = 真實市場情況
差異越大 = 市場越不"正常"，風險評估需要更小心
```

---

### 3. 條件波動率 (Conditional Volatility)
**位置**: 左中  
**顏色**: 紅色線條

**什麼是條件波動率？**
- GARCH 模型計算出的"預期波動率"
- 基於歷史數據預測當前的市場不確定性程度

**如何解讀？**
- 📈 **高峰**: 市場恐慌期，價格變化劇烈
- 📉 **低谷**: 市場平靜期，價格相對穩定
- 🔄 **週期性**: 波動率有高低循環（波動聚集現象）

**實際應用**:
```
波動率 2% = 相對平靜，適合加大倉位
波動率 5% = 中等波動，正常交易
波動率 8%+ = 高風險期，建議減倉或避險
```

---

### 4. 標準化殘差 (Standardized Residuals)  
**位置**: 右中  
**顏色**: 綠色線條

**什麼是標準化殘差？**
- 實際收益率 vs GARCH 模型預測的差異
- 經過標準化處理，方便比較

**如何解讀？**
- ✅ **在 ±2 之間**: 模型預測還算準確
- ⚠️ **超出 ±3**: 模型沒預測到的"異常事件"
- 📊 **隨機分散**: 好的模型應該讓殘差看起來隨機

**模型品質指標**:
```
殘差很隨機 = 模型捕捉到大部分波動模式 ✅
殘差有明顯模式 = 模型還有改進空間 ⚠️
異常點很多 = 市場有很多"黑天鵝事件" 🦢
```

---

### 5. 波動率預測 (Volatility Forecast)
**位置**: 左下  
**顏色**: 藍色實線（歷史）+ 紅色虛線（預測）

**這個圖預測什麼？**
- 藍線：過去的波動率（已知）
- 紅線：未來的波動率（GARCH 預測）

**如何使用？**
- 📈 **預測上升**: 未來可能更不穩定，建議：
  - 降低槓桿
  - 增加止損設定
  - 考慮避險工具
- 📉 **預測下降**: 未來可能更平穩，建議：
  - 可適當增加倉位
  - 調整交易頻率

**時間範圍**:
```
短期預測（1-7天）: 比較可靠
中期預測（1-4週）: 參考價值
長期預測（1個月+）: 僅供參考
```

---

### 6. 標準化殘差 Q-Q 圖 (Q-Q Plot)
**位置**: 右下  
**顏色**: 藍色點 + 紅色直線

**Q-Q 圖是什麼？**
- 檢驗標準化殘差是否符合正態分佈
- 每個點代表一個數據點

**如何解讀？**
- ✅ **點接近紅線**: 殘差接近正態分佈，模型假設合理
- ⚠️ **兩端彎曲**: 有"肥尾"現象，極端事件比正態分佈預期的多
- 📊 **整體偏移**: 可能有系統性偏差

**實際意義**:
```
接近直線 = GARCH 模型假設基本正確 ✅
S型曲線 = 市場有更多極端事件，需要更謹慎的風險管理 ⚠️
```

## 🎯 綜合分析指南

### 判斷市場狀態
1. **低波動期** (適合進場):
   - 條件波動率在低位
   - 波動率預測平穩
   - 收益率分佈集中在中間

2. **高波動期** (謹慎操作):
   - 條件波動率飆升
   - 標準化殘差出現異常值
   - Q-Q 圖偏離直線嚴重

3. **趨勢轉換期** (關鍵時刻):
   - 波動率預測出現轉向
   - 收益率時間序列出現新模式

### 風險管理建議

**根據條件波動率調整策略**:
```python
if 條件波動率 < 2%:
    建議: "低風險期，可適當增加倉位"
elif 條件波動率 < 5%:
    建議: "中等風險，維持正常倉位"  
else:
    建議: "高風險期，建議減倉並加強風控"
```

**根據波動率預測制定計劃**:
- 預測波動率上升 → 準備防守策略
- 預測波動率下降 → 考慮進攻機會
- 預測不確定 → 保持觀望態度

## 📚 延伸學習

### 相關概念
- **波動聚集**: 高波動期後往往跟著高波動期
- **肥尾現象**: 極端事件比正態分佈預期的更常發生  
- **條件異變異數**: 波動率不是固定的，會隨時間變化

### 進階應用
- 結合 VaR/CVaR 進行風險量化
- 配合交易信號進行動態調倉
- 結合宏觀經濟事件解釋波動率變化

💡 **記住**: GARCH 模型是工具，不是水晶球！它幫助我們量化和預測波動率，但市場永遠有意外。把它作為風險管理的參考，而不是交易的唯一依據。
