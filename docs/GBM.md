📈 GBM (Geometric Brownian Motion) 幾何布朗運動原理

  🎯 什麼是 GBM？

  幾何布朗運動是金融數學中最重要的隨機過程之一，被廣泛用於股價模型和期權定價（如
  Black-Scholes 模型）。它是對股價變動的數學描述。

  核心概念

  GBM 假設股價變動由兩個部分組成：
  1. 確定性趨勢 (Drift) - 平均收益率
  2. 隨機波動 (Volatility) - 市場的不確定性

  ---
  📊 數學公式

  GBM 的微分方程

  dS = μS dt + σS dW

  其中：
  - S = 股價（或資產價格）
  - μ = 期望收益率（漂移率，Drift）
  - σ = 波動率（Volatility）
  - dW = 維納過程（布朗運動的增量）
  - dt = 時間增量

  解析解

  S(t) = S(0) * exp((μ - σ²/2) * t + σ * W(t))

  或者對數形式：
  ln(S(t)) = ln(S(0)) + (μ - σ²/2) * t + σ * W(t)

  ---
  🔍 GBM 的重要特性

  1. 對數正態分佈

  - GBM 過程的價格遵循對數正態分佈
  - 價格不會變成負數（符合現實）
  - 收益率遵循正態分佈

  2. 馬可夫性質

  - 未來價格只依賴於當前價格
  - 與歷史路徑無關（無記憶性）

  3. 尺度不變性

  - 相同的統計性質在不同時間尺度上保持

  4. 連續性

  - 價格路徑是連續的（無跳躍）

  ---
  🎲 參數含義詳解

  μ (Drift Rate) - 漂移率

  μ > 0: 上升趨勢 📈
  μ = 0: 無趨勢（純隨機遊走） ➡️
  μ < 0: 下降趨勢 📉

  實務意義：
  - 代表資產的平均年化收益率
  - BTC 歷史 μ ≈ 100-200% （高增長資產）
  - 股票市場 μ ≈ 8-12% （成熟市場）

  σ (Volatility) - 波動率

  σ 越大 = 價格變動越劇烈 📊
  σ 越小 = 價格變動越平穩 📏

  實務意義：
  - 衡量資產的風險水準
  - BTC 歷史 σ ≈ 80-120% （高波動）
  - 股票 σ ≈ 15-30% （中等波動）
  - 債券 σ ≈ 2-8% （低波動）

  ---
  🔬 GBM vs 其他模型比較

  GBM vs ARIMA

  | 特徵  | GBM             | ARIMA        |
  |-----|-----------------|--------------|
  | 基礎  | 連續時間隨機過程        | 離散時間序列       |
  | 假設  | 對數正態分佈          | 線性關係         |
  | 參數  | μ (漂移), σ (波動率) | p,d,q (自回歸項) |
  | 適用  | 長期趨勢預測          | 短期模式捕捉       |
  | 優勢  | 理論基礎強，適合衍生品定價   | 靈活捕捉時間序列特徵   |

  GBM vs GARCH

  | 特徵  | GBM      | GARCH    |
  |-----|----------|----------|
  | 波動率 | 常數波動率    | 時變波動率    |
  | 複雜度 | 簡單（2個參數） | 複雜（多個參數） |
  | 現實性 | 理想化假設    | 更符合實際    |
  | 用途  | 理論定價     | 風險管理     |

  🔢 實務計算範例

  假設 BTC 當前價格 $50,000：

  參數估計

  μ = 0.8  # 80% 年化收益率
  σ = 1.2  # 120% 年化波動率
  S0 = 50000  # 初始價格
  T = 1  # 1年後

  1年後價格分佈

  # 期望價格
  E[S(1)] = S0 * exp(μ * T) = 50000 * exp(0.8) ≈ $111,303

  # 價格標準差
  Std[S(1)] = S0 * exp(μ * T) * sqrt(exp(σ²*T) - 1) ≈ $171,234

  價格區間預測（95%信心區間）

  下界：約 $23,000
  上界：約 $540,000

  ⚠️ GBM 的限制與假設

  主要限制

  1. 常數參數假設
    - 現實中 μ 和 σ 會隨時間變化
    - 特別是波動率聚集現象
  2. 無跳躍假設
    - 現實中存在價格跳躍（如黑天鵝事件）
    - 加密貨幣市場尤其明顯
  3. 對數正態假設
    - 實際收益率可能有肥尾特徵
    - 極端事件比模型預測更常見
  4. 無均值回歸
    - GBM 假設趨勢會無限延續
    - 現實中資產價格有週期性

  改進方向

  # 基礎 GBM
  dS = μS dt + σS dW

  # 跳躍擴散模型 (Merton Jump Diffusion)
  dS = μS dt + σS dW + S dJ

  # 隨機波動率模型 (Heston)  
  dS = μS dt + √V S dW₁
  dV = κ(θ-V) dt + σᵥ√V dW₂

  # 均值回歸 GBM
  dS = κ(θ-lnS)S dt + σS dW
