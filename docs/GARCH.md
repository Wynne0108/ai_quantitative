 📚 GARCH 模型原理詳解

  🎯 什麼是 GARCH？

  GARCH = Generalized Autoregressive Conditional 
  Heteroskedasticity(廣義自回歸條件異方差性模型)

  🤔 為什麼需要 GARCH？

  ARIMA 的局限性：

  - ARIMA 預測價格平均值
  - 假設波動率恆定 (同方差性)
  - 但實際上：市場波動率是變化的！

  加密貨幣的特徵：

  - 🌪️  波動率聚集: 高波動期後跟著高波動期
  - 📈 不對稱性: 下跌時波動率增加更快
  - ⚡ 厚尾分佈: 極端事件比正態分佈預測的更頻繁

  📊 GARCH 模型數學原理

  基本 GARCH(1,1) 模型：

  1. 收益率方程：
  r_t = μ + ε_t
  ε_t = σ_t × z_t
  2. 波動率方程：
  σ²_t = ω + α × ε²_{t-1} + β × σ²_{t-1}

  其中：
  - r_t = 第 t 期收益率
  - σ²_t = 第 t 期條件方差（波動率平方）
  - ε_t = 殘差項
  - z_t = 標準化隨機項 (通常為標準正態分佈)
  - ω, α, β = 模型參數

  參數含義：

  - ω (omega): 長期波動率水平
  - α (alpha): 短期衝擊的影響 (ARCH 項)
  - β (beta): 波動率持續性 (GARCH 項)

  🔍 GARCH vs ARIMA 對比

  | 特徵   | ARIMA  | GARCH |
  |------|--------|-------|
  | 預測目標 | 價格/收益率 | 波動率   |
  | 假設   | 等方差    | 異方差   |
  | 適用於  | 趨勢預測   | 風險管理  |
  | 輸出   | 點預測    | 波動率預測 |

  💡 GARCH 的實際應用

  1. 風險管理 📉

  - 計算 VaR (風險價值)
  - 投資組合風險評估
  - 期權定價

  2. 交易策略 📈

  - 波動率交易
  - 動態避險
  - 倉位調整

  3. 市場分析 🔍

  - 識別高風險期間
  - 市場情緒分析
  - 危機預警

  🚀 GARCH 模型的優勢

  對加密貨幣特別有效：

  1. 捕捉波動率聚集：牛市/熊市的波動模式
  2. 適應性強：自動調整預測
  3. 風險量化：提供精確的風險測量

  📈 常見 GARCH 變種

  1. GARCH(p,q): 基本模型
  2. EGARCH: 考慮不對稱效應
  3. GJR-GARCH: 區分正負衝擊
  4. TGARCH: 門檻效應
